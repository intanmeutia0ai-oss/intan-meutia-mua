# Intan Meutia — Makeup Artist & Bridal Stylist

Website portofolio dan reservasi layanan Makeup Artist profesional oleh **Intan Meutia**, melayani wilayah **Banda Aceh dan sekitarnya**.

## ✨ Fitur Utama
- **Portofolio & Galeri**: Rias pengantin modern, adat Aceh & nusantara, Korean glow graduation/wisuda, dan pre-wedding.
- **Daftar Layanan & Paket**: Paket Bridal, Korean Glow Graduation (Wisuda/Sidang), Engagement, Pre-wedding, dan Event Glam.
- **Kalkulator Estimasi Biaya**: Perhitungan harga fleksibel dengan pilihan add-on (retouch, hairdo/hijab do, transportasi).
- **Formulir Reservasi WhatsApp**: Formulir booking interaktif yang otomatis menghasilkan draf pesan pemesanan ke WhatsApp resmi.
- **Kuis Rekomendasi Makeup (Beauty Consultation Quiz)**: Membantu calon klien menemukan gaya makeup yang paling sesuai.

## 🚀 Memulai Proyek (Getting Started)

### Prasyarat
- Node.js (versi 18 atau lebih baru)
- npm / yarn / pnpm / bun

### Instalasi & Menjalankan Dev Server
```bash
# Install dependencies
npm install

# Jalankan server pengembangan lokal (port 3000)
npm run dev
```

Buka peramban di `http://localhost:3000`.

### Build untuk Produksi
```bash
npm run build
```

Hasil build akan tersimpan di folder `dist/`.

## 📤 Push ke GitHub

Jika Anda ingin mengunggah repositori ini ke GitHub:

```bash
# 1. Pastikan branch utama bernama main
git branch -M main

# 2. Hubungkan dengan repository remote Anda di GitHub
git remote add origin https://github.com/<USERNAME-ANDA>/<NAMA-REPO-ANDA>.git

# 3. Push ke GitHub
git push -u origin main
```
